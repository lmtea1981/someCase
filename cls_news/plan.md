# 财联社新闻获取工具计划

## 项目目标
从财联社网站（https://www.cls.cn/）获取最新的头条信息和电报信息，并支持查看详细内容。

## 技术方案
1. **使用Node.js**作为运行环境
2. **使用axios**库发送HTTP请求获取页面内容
3. **使用cheerio**库解析HTML结构提取信息
4. **使用readline**模块实现交互式查询

## 实现步骤
1. **创建项目结构**
   - 初始化package.json文件
   - 安装必要的依赖包

2. **实现核心功能**
   - 编写fetchPage函数获取页面内容
   - 编写extractHeadlines函数提取头条新闻
   - 编写extractTelegrams函数提取电报信息
   - 编写getNewsDetail函数获取新闻详细内容
   - 编写displayHeadlines和displayTelegrams函数展示信息
   - 编写main函数实现交互式查询

3. **测试与优化**
   - 测试获取头条新闻功能
   - 测试获取电报信息功能
   - 测试查看详细内容功能
   - 优化选择器以适应网站结构变化

## 预期结果
- 能够成功获取财联社网站的头条新闻
- 能够成功获取财联社网站的电报信息
- 能够根据用户选择查看详细内容
- 提供友好的交互式界面

## 项目结构
```
cls_news/
├── package.json          # 项目配置文件
├── index.js              # 主程序文件
├── get_html.js           # 辅助脚本，用于获取HTML结构
└── cls.html              # 保存的HTML文件（用于分析）
```

## 依赖包
- axios: ^1.6.2
- cheerio: ^1.0.0-rc.12

## 运行方式
1. 安装依赖：`npm install`
2. 运行程序：`node index.js`
3. 按照提示选择要查看的内容类型和序号

## 注意事项
- 财联社网站的HTML结构可能会变化，需要定期更新选择器
- 网站可能会有反爬虫机制，需要设置合理的请求头
- 详细内容的提取可能需要根据不同页面结构进行调整
