# 构建基于RAG的测试用例智能检索系统

## 1. 模块拆分与文件创建

- **config.py**：统一配置管理（模型、路径、文本处理参数、测试设计方法列表）
- **tool/__init__.py**：封装通用文档加载工具，支持Excel核心格式，包含文本预处理、空行过滤逻辑
- **case_analyzer.py**：批量分析用例设计方法，实现流式输出分析过程
- **case_retriever.py**：交互式检索，获取用户需求并流式输出匹配结果

## 2. 核心功能实现

### 2.1 配置管理（config.py）
- 模型配置：Ollama大模型和嵌入模型参数
- 文本处理参数：chunk_size=300, chunk_overlap=30
- 测试设计方法列表：等价类划分法、边界值分析法、异常分析法、场景法、因果图法、正交试验法、判定表法
- 路径配置：用例库路径、数据库路径等

### 2.2 文档加载工具（tool/__init__.py）
- Excel文档加载与解析
- 空行过滤与有效数据提取
- 文本预处理与清洗
- 支持多类型文档扩展（可选）

### 2.3 用例分析器（case_analyzer.py）
- 加载Excel用例库
- 文本拆分与向量嵌入
- LLM流式分析用例设计方法
- SQLite持久化存储

### 2.4 用例检索器（case_retriever.py）
- 交互式获取用户测试目的
- 分析匹配的设计方法
- 向量检索与SQLite筛选
- 流式输出匹配结果

## 3. 技术栈与依赖

- langchain 1.2
- faiss-cpu 1.13.2
- sqlite3
- ollama
- pandas
- python-docx（可选）
- pypdf2（可选）

1. 创建所有模块文件

3. 实现文档加载工具
4. 实现用例分析器
5. 实现用例检索器
